# 🌅 Daily Briefing — 2026-05-25

## 🤖 AI & เทคโนโลยี

### Google I/O 2026 — เดิมพันทุกอย่างกับ AI
- **Gemini 3.5 Flash** เปิดตัวอย่างเป็นทางการ มีประสิทธิภาพระดับ frontier ในราคาถูกกว่าคู่แข่งถึง 50–67% เหมาะกับงาน enterprise ขนาดใหญ่
- **Gemini Spark** — AI agent ตัวใหม่ที่ reasoning ข้ามแอปที่เชื่อมต่อกันได้ทั้งหมด (Gmail, Drive, Calendar)
- Google ปรับ Search ใหม่รองรับทั้ง short query แบบเดิม และ chatbot-style conversation พร้อม **"Ask YouTube"** ที่ตอบคำถามพร้อมแสดงลิงก์วิดีโอ

### Anthropic — Claude Opus 4.7 พร้อมใช้แล้ว
- **Claude Opus 4.7** เปิดให้ใช้งานทั่วไปแล้ว เด่นด้าน software engineering และ coding task ที่ซับซ้อน รองรับรูปภาพความละเอียดสูงขึ้น
- ราคาคงเดิม: $5 / million input tokens | $25 / million output tokens
- **Dreaming** — ฟีเจอร์ใหม่ใน Managed Agents API ช่วยจัดระเบียบ persistent memory ระหว่าง session โดยอัตโนมัติ
- ผู้เชี่ยวชาญในอุตสาหกรรมระบุว่า **Claude Mythos** ทำให้ Anthropic ก้าวขึ้นนำในการแข่งขัน AI frontier

### Big Tech — ทุ่มงบ Data Center สูงสุดเป็นประวัติการณ์
- Google, Amazon, Microsoft และ Meta วางแผนใช้จ่าย **$725 พันล้านดอลลาร์** ด้าน capex ในปี 2026 (+77% จากปีก่อน)
  - Microsoft: $190 พันล้าน | Meta: $125–145 พันล้าน
- **Meta** ปลดพนักงาน 10% (~8,000 คน) ควบคู่ไปกับการลงทุน AI อย่างหนัก
- **Microsoft** เปิดโปรแกรม voluntary buyout สำหรับพนักงานสหรัฐฯ ราว 7%
- **Apple** เลือกทางแตกต่าง — ร่วมมือกับ Google พัฒนา foundation model สำหรับ Siri แทนการสร้าง data center ของตัวเอง
- **OpenAI** ประกาศเดินหน้าธุรกิจโฆษณา AI เล็งเป้าตลาด **$100 พันล้าน** ภายในปี 2030
