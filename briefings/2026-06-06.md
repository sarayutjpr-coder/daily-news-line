# Daily Briefing — 2026-06-06

## AI & Technology

- **Google เปิดตัว Gemini 3.5 และ Gemini Omni — ยุค Agentic AI อย่างเป็นทางการ** — Google เข้าสู่ยุค Agentic AI ด้วยการเปิดตัว Gemini 3.5 ที่ออกแบบมาสำหรับ AI Agents และ Coding โดยเฉพาะ พร้อมด้วย Gemini Omni ที่รับ input ได้ทั้งภาพ เสียง วิดีโอ และข้อความ แล้วสร้างวิดีโอคุณภาพสูงได้
- **Anthropic ยื่นไฟล์ IPO มูลค่าเกือบ 1 ล้านล้านดอลลาร์ — แซง OpenAI** — Anthropic เซอร์ไพรส์ตลาดด้วยการยื่น IPO แบบ Confidential ก่อน OpenAI พร้อมปิดรอบระดมทุนที่มูลค่า 9.65 แสนล้านดอลลาร์ โดยมี Claude Code เป็นแรงขับเคลื่อนสำคัญที่ทำให้บริษัทแซงหน้า OpenAI เป็นครั้งแรก
- **Claude Opus 4.8 — Context Window 1 ล้าน Token และ Mythos Model ขยายพันธมิตร** — Anthropic เปิดตัว Claude Opus 4.8 พร้อม default context 1 ล้าน token รองรับ Coding ที่ซับซ้อน และขยายการเข้าถึง Mythos Model ให้พันธมิตรเพิ่มอีก 150 ราย เพื่อตรวจจับช่องโหว่ซอฟต์แวร์
- **Microsoft และ Google รุกตลาด AI Coding ไล่ตาม Anthropic** — Microsoft เตรียมประกาศผลิตภัณฑ์ Coding ในงาน Build Conference ขณะ Google เน้นผลิตภัณฑ์ใหม่ใน Google I/O เดือนพฤษภาคม ทั้งสองพยายามดึงส่วนแบ่งตลาดจาก Claude Code ที่ครองตลาด AI Coding อยู่
- **NASA ส่ง Perseverance Rover บนดาวอังคารด้วย AI** — Perseverance สร้างประวัติศาสตร์ด้วยการขับเคลื่อนบนดาวอังคารโดยใช้เส้นทางที่วางแผนโดย AI แทนมนุษย์ เป็นก้าวสำคัญในการสำรวจอวกาศอัตโนมัติ
- **การใช้ AI ทั่วโลกเพิ่มขึ้นเป็น 17.8% ของประชากรวัยทำงาน** — รายงานจาก Microsoft ระบุว่าการใช้ AI ในชีวิตประจำวันเพิ่มขึ้น 1.5% จากไตรมาสที่แล้ว โดยมี 26 ประเทศที่ประชากรวัยทำงานกว่า 30% ใช้ AI แล้ว
